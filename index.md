# AvroSharp

A high-performance, Native AOT-friendly .NET implementation of the [Apache Avro™](https://avro.apache.org/) specification.

- **[Guide](README.md):** schemas and the generic data model, container files and codecs, single-object messages and schema registries, streams, and code generation from `.avsc` files.
- **[API reference](docs/api/index.md):** every public type, from the XML documentation.
- **[Roadmap](docs/roadmap.md):** what is done and what comes next.
- **[Design](docs/design.md):** the design proposal and the decisions made since.

The source, issues and samples are on [GitHub](https://github.com/zcsizmadia/AvroSharp).
