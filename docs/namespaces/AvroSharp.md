The exceptions that every AvroSharp namespace raises. [`AvroException`](xref:AvroSharp.AvroException) is the base class. [`AvroDataException`](xref:AvroSharp.AvroDataException) is raised when binary data is malformed or truncated, and [`AvroSchemaException`](xref:AvroSharp.AvroSchemaException) when a schema is invalid, whether it is parsed from JSON or built in code. The rest of the API is in the namespaces below this one, starting with <xref:AvroSharp.Schemas>.
