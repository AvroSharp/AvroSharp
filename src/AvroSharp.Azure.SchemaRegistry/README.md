# AvroSharp.Azure.SchemaRegistry

An [Azure Schema Registry](https://learn.microsoft.com/azure/event-hubs/schema-registry-overview) serializer on [AvroSharp](https://github.com/AvroSharp/AvroSharp), for Event Hubs and Service Bus messages (`MessageContent`), as a replacement for `Microsoft.Azure.Data.SchemaRegistry.ApacheAvro`, without Apache.Avro.

> **Status:** planned, not started. This folder holds its place: the package will be built here and released with AvroSharp, at the same version. It's tracked in [#155](https://github.com/AvroSharp/AvroSharp/issues/155), and the [integrations page](https://avrosharp.github.io/AvroSharp/docs/integrations.html) has the plan for every add-on package.
