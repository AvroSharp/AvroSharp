# AvroSharp.Aws.Glue

A fully managed [AWS Glue Schema Registry](https://docs.aws.amazon.com/glue/latest/dg/schema-registry.html) serializer on [AvroSharp](https://github.com/AvroSharp/AvroSharp), for every platform .NET runs on. AWS's own .NET serializer wraps a native library that runs on Linux only.

> **Status:** planned, not started. This folder holds its place: the package will be built here and released with AvroSharp, at the same version. It's tracked in [#156](https://github.com/AvroSharp/AvroSharp/issues/156), and the [integrations page](https://avrosharp.github.io/AvroSharp/docs/integrations.html) has the plan for every add-on package.
