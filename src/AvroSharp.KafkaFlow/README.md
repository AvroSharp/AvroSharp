# AvroSharp.KafkaFlow

[KafkaFlow](https://github.com/Farfetch/kafkaflow) serializers on [AvroSharp](https://github.com/AvroSharp/AvroSharp) and [AvroSharp.Confluent](../AvroSharp.Confluent/README.md), as a replacement for `KafkaFlow.Serializer.SchemaRegistry.ConfluentAvro`, without Apache.Avro.

> **Status:** planned, not started. This folder holds its place: the package will be built here and released with AvroSharp, at the same version. It's tracked in [#154](https://github.com/AvroSharp/AvroSharp/issues/154), and needs one serializer for several types on one topic first ([#192](https://github.com/AvroSharp/AvroSharp/issues/192)). The [integrations page](https://avrosharp.github.io/AvroSharp/docs/integrations.html) has the plan for every add-on package.
